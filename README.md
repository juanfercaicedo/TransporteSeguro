[PRODUCTO MÍNIMO VIABLE](http://juanfercaicedo.github.io/TransporteSeguro/)

La landing en `index.html` abre el selector de rol (`src/html/app-index.html`). La vista estudiante permite escribir direcciones y comparar alternativas de transporte público en Google Maps; la vista familiar muestra el último viaje y un mapa centrado en la última ubicación compartida desde el mismo navegador.

Los módulos están separados por responsabilidad: `src/models`, `src/views`, `src/controllers`, `src/services` y `src/config`. Desde Ajustes, la vista familiar puede agregar/quitar perfiles y ver cuántos hijos ha registrado en este navegador; la vista estudiante puede escoger el perfil activo o agregar uno. El viaje guardado se asocia al perfil activo, aunque este prototipo conserva y muestra un solo viaje reciente a la vez. La vista estudiante solicita permiso explícito para compartir la ubicación; el prototipo la guarda solo en el almacenamiento local del navegador. La vista familiar muestra ese último reporte (no seguimiento en tiempo real). Los perfiles, la familia y el estudiante deben abrir la aplicación desde el mismo origen y navegador para ver actualizaciones. No hay backend, inicio de sesión, sincronización entre dispositivos ni notificaciones reales.

Para habilitar el mapa y el cálculo integrado en GitHub Pages, crea un secreto de Actions llamado `GOOGLE_MAPS_API_KEY` en Settings → Secrets and variables → Actions del repositorio y vuelve a ejecutar el workflow de Pages (o publica un nuevo cambio). Habilita Maps JavaScript API y Directions API (Legacy) con facturación configurada. La clave se inyecta en un módulo JavaScript durante el despliegue, no en HTML ni en los archivos fuente. Como toda clave usada desde una web estática es visible para el navegador, restrínjela por referente HTTP al dominio de GitHub Pages y por API; no la uses como secreto de servidor. Sin la variable configurada, la vista estudiante muestra un enlace para abrir esas direcciones en Google Maps, pero no puede mostrar el mapa ni calcular alternativas dentro de la app.

La clave que anteriormente estaba escrita directamente en los archivos del proyecto debe revocarse y reemplazarse en Google Cloud antes de publicar.

En la vista estudiante se ingresa un punto de partida y un destino. Google Maps calcula el recorrido de transporte público y la app muestra la parada sugerida para subir, la parada de bajada, las indicaciones a pie y alternativas ordenadas por duración. La lista de nombres de líneas compartida como texto no contiene paradas georreferenciadas ni trazados; por eso no se usa como una fuente de cálculo ni se dibujan recorridos propios a partir de ella. Para operar rutas propias hacen falta datos estructurados de paradas y recorridos, como un feed GTFS con coordenadas.
